# Home Assistant dashboard

Use a standard Entities card and select the integration's Connectivity, Last gateway update, Queue depth, Queue drops, Transport drops and Observed sequence gaps entities from the device page. Entity IDs depend on the name and registry of the Home Assistant installation.

The planned vehicle view groups battery, fuel and range into an overview, access status into a separate card, and charging and climate into their own sections. Add each section as verified Passat entities become available. Capture actions are available in Developer Tools.
